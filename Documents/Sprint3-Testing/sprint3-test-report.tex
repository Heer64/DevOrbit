\section{Test development findings}
The following were test setup or automation issues encountered and corrected; they were not confirmed production defects:
\begin{itemize}
\item Chromium headless shell was initially missing; the Playwright browser was installed.
\item A member list on the owner's page required reload after invitation acceptance before checking the Remove action.
\item Mention-capable textareas use the ARIA \texttt{combobox} role, so \texttt{textbox} locators were corrected.
\item Thread selectors were scoped to the channel list to avoid matching both the parent and thread copies of the message.
\item Task comments were opened through the task's Edit button.
\end{itemize}
