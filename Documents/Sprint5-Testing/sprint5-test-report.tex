\section{Automation findings and changes}
The post-lifecycle test originally timed out while trying to click \texttt{Save} after editing post text. The locator matched the card using its \emph{old} text, but the edited text had changed. The test was corrected to locate the editor's Save action directly; the rerun showed both community tests passing. This was a \textbf{test selector issue}, not a confirmed application defect.
\par\smallskip\noindent A representative example of the corrected locator strategy:
\begin{quote}\small\ttfamily
await editForm.getByRole('button', \{ name: 'Save', exact: true \}).click();
\end{quote}
This snippet illustrates the test strategy; actual submitted source remains in the Playwright spec file.
